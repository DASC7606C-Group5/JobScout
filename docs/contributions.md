# 实际实施与验证记录

- 基于现有源码核实差距，确认全范围实现及跨补充检索轮累计预算。
- 保留现有未提交模型草稿和依赖改动；将原规范保存为 `docs/implementation-plan.md`，并固定原规则画像/推荐 baseline 用于公平评估。
- 扩展共享 Pydantic 契约：对话、typed controls、跳过、摘要确认版本、来源文档、证据理由、不限类型和异步快照。
- 实现异步会话操作管理：快速返回 accepted snapshot、请求幂等、revision 冲突、单操作、删除取消和迟到写入保护。
- 更新 HTTP 路由并新增可注入应用生命周期，保留简历解析接口。
- 编写离线操作/HTTP 测试，覆盖重复提交、旧版本、非法问题/选项、确认门槛、类型错误、删除及会话隔离。
- 更新会话 API、共享契约及开发指南中与新规范冲突的说明。

- 实现原生异步 DeepSeek provider、类型化输出校验、限时重试及安全错误；添加离线 provider 测试。
- 实现生产澄清/摘要确认图、条件更正和限次补检，保留原规则图供基线回归。
- 实现异步四来源检索、来源诊断、原文保留、均衡候选和证据评分；完成四来源独立 live 检索记录。
- 实现中文对话控件、可编辑摘要、证据卡片、会话恢复与轮询，保留原有上传、过滤和收藏；添加单元及浏览器测试。
- 固定 12 个合成用户与 30 个标注岗位、原规则 baseline 和可执行评估；恢复中断的评估交付，明确 authored replay 不是真实模型效果。
- 修复集成中发现的摘要版本、删除迟到响应、失败重试 checkpoint 隔离及回放地点别名问题，补充针对性回归。

上述工作由本轮 AI 辅助实施；不声称经过独立人工 review。确切检查结果见 [验证记录](validation.md)。DeepSeek live 尚无凭证，不能记为完成。

## 验证原则

- 测试通过仅表示对应命令与当前代码在所记录环境中通过，不代表外部来源或真实模型一定可用。
- Synthetic fixtures、回放结果和 live 调用必须分开记录。
- 未配置凭证、来源拦截、环境缺失或未执行检查必须明确列为限制，不能补写成功结果。
- 演示与提交材料中不包含真实私密简历、供应商密钥或模型私有推理。
