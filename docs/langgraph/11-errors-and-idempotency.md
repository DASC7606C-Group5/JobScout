# 错误处理、重试与幂等性

[返回学习入口](README.md) · 适用：第 3、4、5 组；其他组按需 · 前置：[LLM、Service 与 API/Graph 边界](10-llm-services-and-boundaries.md)

先区分错误类别：

- **输入错误**：例如缺少必要求职信息。向用户澄清或返回可操作的校验错误。
- **可重试外部错误**：例如限流或暂时性网络错误。设置超时、有限次数重试和退避。
- **不可重试错误**：例如无效凭证或接口 schema 改变。记录上下文并尽早失败，不要无限重试。
- **部分结果**：部分岗位来源不可用时是否继续，属于明确的产品/业务决策。

短暂网络错误的重试尽量放在对应 Service；只有重试需要 workflow 状态、分支或人工干预时，才建模为 graph 路径。错误记录应避免泄漏堆栈、密钥或简历原文。

节点可能因重试、恢复或 interrupt 再次执行。写数据库、创建记录等副作用应使用幂等键或可重复安全的 upsert。外部请求应有超时与速率限制。
