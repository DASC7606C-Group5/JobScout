# 测试 graph

[返回学习入口](README.md) · 适用：所有后端小组，尤其第 3 组 · 前置：[State、Node、Edge 与路由](03-state-nodes-routing.md)

把业务纯函数、服务和 graph 分开测：

1. **单元测试**：画像校验、技能差距、排序和格式化；输入输出确定，不依赖模型/API。
2. **节点测试**：给 node 一个最小 State，检查返回的局部更新。
3. **路由测试**：覆盖信息完整与不完整时的目标节点。
4. **Graph 集成测试**：注入 Mock services，验证主路径和澄清路径。
5. **暂停/恢复测试**：使用内存 checkpointer，验证相同 `thread_id` 恢复、resume 值进入状态、不同 thread 不串状态。
6. **服务契约测试**：验证外部数据能转换为内部约定结构。

普通单元测试不要依赖真实 LLM 输出或实时岗位数据。涉及 LLM 时测试输入构造、结构化结果校验和失败回退；端到端真实模型测试应独立标记并控制成本。

项目最低测试场景和验收条件以[开发指南第 7 节](../JobScout_Development_Guide.md#7-最低测试场景)为准。
