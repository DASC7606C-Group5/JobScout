# 从 Mock 逐步接入真实服务

[返回学习入口](README.md) · 适用：第 3、4、5、6 组 · 前置：[测试 graph](12-testing.md)

建议按可验证的小步推进：

1. 用固定简历和岗位样本让 graph 完整运行。
2. 将画像提取替换为 schema 约束的模型调用；校验缺字段、类型错误和模型拒答。
3. 将 Mock 岗位源替换为一个真实 API，并在 Service 层转换为内部岗位契约。
4. 增加去重、空结果、限流、超时和 API 失败测试。
5. 加入持久 checkpointer 和会话恢复，再连通前端澄清交互。
6. 根据实测结果评估并行岗位源、subgraph 或模型 Agent 循环。

每一步保持 graph 输入输出契约稳定；Service 变化不应迫使 API 层知道第三方 API 细节。外部来源、简历格式、后端框架和 session 持久化仍待团队确认；在确认前，继续用开发指南规定的正式契约和固定 Mock 开发。
